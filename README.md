# WearWild privacy policy

The privacy policy for the WearWild Chrome extension (a pixel-art threatened-species companion that keeps you company on fashion sites and asks before you buy).

It is published with GitHub Pages at the URL on the right of this repository. The policy is a single static page, `index.html`, with no scripts and no tracking.

WearWild is made by Group 1, Inventing Futures, University of Sydney.
